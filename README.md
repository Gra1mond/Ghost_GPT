# Ghost GPT

Русскоязычный Windows AI-assistant. MIT. Собственный API-ключ, без сервера проекта.

Разработка: .NET 10 SDK, `dotnet build src/GhostGPT/GhostGPT.csproj`.
Запуск: `dotnet run --project src/GhostGPT/GhostGPT.csproj`.

Функции добавляются отдельными зависимыми pull requests. Не реализованные действия обозначены в интерфейсе.
