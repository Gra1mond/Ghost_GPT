# ◈ Ghost GPT

Windows AI-помощник с собственным API-ключом, плавающим окном и русским интерфейсом. C# / .NET 10 / WPF. MIT.

## Запуск

Распакуйте **весь** `GhostGPT-win-x64.zip` и запустите `GhostGPT.exe`. Установка .NET не требуется. Windows x64, Windows 10 2004+ / Windows 11. Сборка не подписана цифровым сертификатом.

ZIP создаётся workflow **Windows** в GitHub Actions. Последняя ветка цепочки PR содержит полный MVP. PR не сливаются автоматически; после слияния предыдущего PR смените base следующего на `main`.

## Подключение прямо в приложении

### Wellflow

Готовая настройка **Wellflow · GPT-5.6 Sol** использует `https://api.wellflow.dev/v1` и модель `gpt-5.6-sol`. На новой установке эти значения уже выбраны; существующие настройки сохраняются. Нажмите кнопку Wellflow, вставьте свой ключ в скрытое поле и сохраните подключение. Ключ не включён в исходники или сборку.

Кнопка **Загрузить модели провайдера** читает `/v1/models` и позволяет выбрать другой ID, в том числе `gpt-6-sol`. Это отдельная модель, не псевдоним GPT-5.6 Sol. При переключении с другого сервиса готовая настройка очищает его ключ и отдельную vision-модель. Адрес и модель остаются доступными для ручного редактирования.

Поддержка Wellflow для транскрибации и изображений не подтверждена: настройки речи остаются отдельными.

### Произвольный совместимый API

1. Откройте **Настройки → Подключение ИИ**.
2. Укажите адрес OpenAI-совместимого API, включая `/v1`, точный ID модели и ключ в скрытом поле **API-ключ**.
3. Нажмите **Сохранить подключение**. Ключ шифруется Windows DPAPI для текущего пользователя. Чтобы удалить ключ, очистите поле и сохраните.
4. **Проверить ключ** обращается к `/models`. Успех не гарантирует доступ к каждой модели; некоторые совместимые сервисы не реализуют этот маршрут.
5. Задайте вопрос в **Чате**. Изменённые поля используются сразу; сохранение нужно для следующего запуска.

Для изображений можно указать отдельную vision-модель. Для транскрибации задайте **отдельные** адрес, модель и ключ в разделе распознавания речи. ID моделей намеренно не зафиксированы: возьмите доступные у своего провайдера.

## Возможности

Интерфейс с боковой навигацией: **Чат**, **Разговор**, **Настройки**. На узком окне панель превращается в компактные иконки. **Enter** отправляет сообщение, **Shift+Enter** вставляет новую строку. Ответы прокручиваются автоматически, пока вы не начали читать выше.

Настройки разделены на **Подключение**, **Речь** и **Окно**. Во вкладке **Окно** ползунок меняет прозрачность только фона (0–85%); яркость и прозрачность текста/кнопок остаются неизменными. Окно можно растянуть за нижний правый угол. Сохранённое значение старого ползунка используется как плотность фона.

При запуске автоматически исправляется известная ошибка старой сборки: ключ Wellflow вместе с адресом OpenAI. Это исправление сохраняет модель и зашифрованный ключ; другие провайдеры не изменяются.

- Окно поверх приложений, прозрачность, компактный режим с последним ответом.
- Потоковый чат, отмена, Markdown (заголовки, списки, выделение, блоки кода), копирование.
- Выбор области экрана, предпросмотр и отправка изображения только по нажатию.
- Микрофон и системный звук через WASAPI. Фрагменты WAV до 6 секунд, очередь из 4; при отставании сервиса отображается пропуск.
- Ответ по разговору с пользовательским контекстом и резюме ранних реплик. Запись не останавливается при генерации.

| Сочетание по умолчанию | Действие |
|---|---|
| Ctrl+Shift+Space | Вернуть поверх приложений / отправить назад |
| Ctrl+Shift+Enter | Ответ по разговору |
| Ctrl+Shift+S | Выбрать область экрана |
| Ctrl+Shift+H | Скрыть и остановить запись/генерацию |

Клавиши меняются в настройках окна. При конфликте показывается сообщение; если возврат окна не зарегистрирован, кнопка сворачивания использует панель задач. Обычное скрытие **не останавливает запись**.

## Данные и ограничения

Ключи и настройки находятся в `%LOCALAPPDATA%\GhostGPT\settings.json`; ключи зашифрованы DPAPI. История чатов сохраняется локально в `chats.protected`, зашифрованном DPAPI для текущего пользователя Windows. Удаление: правый клик по чату → «Удалить чат». Снимки, транскрипция и аудио отдельно на диск не записываются. Данные отправляются выбранному API, политика хранения которого задаётся провайдером. Loopback слышит все приложения на выбранном устройстве, включая уведомления. Ключ нельзя перенести на другую учётную запись Windows копированием настроек.

Исключение окна из захвата использует `WDA_EXCLUDEFROMCAPTURE` и отображает результат применения. Это не гарантия невидимости во всех программах записи. Проверьте свой способ демонстрации по [чек-листу](docs/VALIDATION.md).

Максимум 100 сообщений отображения, 40 сообщений истории чата; последние 12k символов разговора плюс резюме до 4k символов. До 24k ранних символов ожидают резюмирования. При переполнении старые данные удаляются с уведомлением. Новые ответы могут вызывать дополнительные платные запросы резюмирования. Сегментация речи простая, по уровню сигнала; диаризации людей нет. Остановка отменяет очередь, хвост текущего фрагмента отбрасывается.

## Разработка

```powershell
dotnet build src/GhostGPT/GhostGPT.csproj -c Release
dotnet run --project tests/GhostGPT.Checks -c Release
dotnet run --project src/GhostGPT/GhostGPT.csproj
dotnet publish src/GhostGPT/GhostGPT.csproj -c Release -r win-x64 --self-contained true -o artifacts/GhostGPT-win-x64
```

Для PNG-предпросмотров WPF: `dotnet run --project tests/GhostGPT.Checks -c Release -- --render`. Проверки используют поддельные HTTP-ответы и временный каталог настроек; API-ключ не нужен.

Архитектура: `ViewModels` содержит состояние чата, `Services` — интерфейсы провайдеров, контекст и Win32/WASAPI, `Controls` — Markdown и выбор области. Части `MainWindow` соединяют UI с этими слоями. Отдельного backend нет.

Контракты: [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [транскрибация](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create), [Windows capture affinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).

### Локальное обновление интерфейса

Перетаскивайте свободную область заголовка; двойной щелчок разворачивает окно. Размер меняется за любой край или угол. Кнопка разворачивания сохраняет панель задач, F11 включает полный экран, Escape возвращает обычный режим. Кнопка «За другие окна» снимает закрепление и отправляет Ghost назад. Ctrl+Shift+Space возвращает его поверх приложений с фокусом ввода. Запись при этом продолжается; Ctrl+Shift+H останавливает её.

Ползунок рядом с вводом изменяет прозрачность фона, не яркость и не прозрачность текста. Он также доступен в настройках окна. История находится слева (в узком окне расширьте его до 900 px). Новый чат сохраняет предыдущий. Скриншоты в историю не сохраняются и при повторном открытии недоступны модели.

Вывод потоковых фрагментов объединяется с интервалом 45 мс, готовый Markdown переиспользуется. В статусе указано время до первого фрагмента и полное время запроса; задержка самого провайдера от оформления окна не зависит. Остановленный ответ тоже остаётся в истории.

### Снимки и инструкции для собеседований

«Снимок» и Ctrl+Shift+S захватывают весь виртуальный рабочий стол (все мониторы). Кнопка «Область» позволяет выбрать фрагмент. Изображение появляется в предпросмотре и отправляется только после нажатия «Отправить».

`INTERVIEW.md` рядом с GhostGPT.exe задаёт формат ответов: краткий ответ вслух, технические объяснения, код и сложность, архитектурные компромиссы, STAR без вымышленного опыта, режим тренировочного собеседования. Файл перечитывается перед каждым ответом в чате и по разговору. Настройки содержат дополнительные сведения о вакансии и вашем опыте. После изменения файла пересборка не нужна. В исходниках файл лежит в корне проекта, в сборку копируется автоматически. При обновлении сборки перенесите свои изменения файла вручную.
