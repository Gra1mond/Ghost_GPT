# Ghost GPT для macOS — отдельный релиз

Нативное приложение SwiftUI/AppKit, macOS 13 Ventura и новее. Windows v0.1.0 остаётся отдельным релизом.

Этот выпуск `mac-v0.1.2-beta.1` подготовлен отдельно от `mac-v0.1.0-beta.1` (macOS 15+). Старые архивы и Windows-релиз сохраняются.

## Изменения 0.1.2

- Экспериментальное исключение главного окна из захвата через `sharingType = .none`; результат зависит от программы демонстрации.
- Кнопка питания в верхней панели: обычный выход с сохранением или принудительное завершение без сохранения.

## Совместимость с Ventura

Микрофон работает через AVFoundation на всех поддерживаемых версиях; при записи только микрофона разрешение на запись экрана не запрашивается. Системный звук получает ScreenCaptureKit. В macOS 13 снимок делается из одного полного кадра SCStream, в macOS 14+ — через SCScreenshotManager. Для прокрутки в macOS 13–14 используется локальный монитор события, без разрешения на универсальный доступ.

## Скачать и установить

На странице macOS-релиза скачайте `GhostGPT-macos13-arm64.zip` для Apple Silicon (M1 и новее) или `GhostGPT-macos13-x86_64.zip` для Intel. Распакуйте и перенесите **Ghost GPT.app** в **Программы**. .NET и Xcode пользователю не нужны.

Сборка имеет локальную ad-hoc подпись, без Developer ID и нотариализации Apple. Gatekeeper может блокировать открытие: разрешите именно это приложение через системные настройки «Конфиденциальность и безопасность», только если доверяете источнику. Не отключайте Gatekeeper целиком. Для обычной подписанной поставки нужны сертификат Developer ID и учётные данные нотариализации владельца проекта.

## Возможности

- Потоковый чат с отменой, Markdown и копированием текста/кода, статус ожидания и анимированный призрак.
- Локальная зашифрованная история, удаление, поиск, папки, переход вниз.
- Редактор INTERVIEW.md с автоматическим сохранением.
- Прозрачный фон, изменение размеров окна и панели, полноэкранный и компактный режимы, поверх/позади других окон.
- Значок в строке меню; Dock-значок скрыт. Закрытие окна скрывает его, выход — через меню приложения.
- Снимок всех экранов и интерактивный выбор области, предпросмотр, удаление и отправка только кнопкой.
- Выбор микрофона, системный звук, отдельный API транскрибации, очередь максимум 4 фрагмента по 6 секунд.
- Ответы по разговору и резюме предыдущего контекста, параллельно с транскрибацией.

## Отличия от Windows

- При создании главного окна, до его показа, автоматически применяется экспериментальный `NSWindow.sharingType = .none`, в том числе на macOS 13 Ventura. Это запрос ограничения доступа к содержимому окна для старых способов захвата, а не гарантия невидимости: ScreenCaptureKit и другие способы записи могут его игнорировать. Отдельного переключателя нет. Проверьте результат со стороны зрителя в используемой программе при демонстрации всего экрана, после скрытия/возврата окна и в полноэкранном режиме. Если окно видно, скрывайте его или демонстрируйте только окно другого приложения. На реальной Ventura эта защита пока не проверена.
- ScreenCaptureKit получает общий звук приложений Mac, а не выбранное WASAPI-устройство вывода. Микрофон выбирается отдельно.
- Снимок всех экранов создаётся в памяти через ScreenCaptureKit. Для интерактивного выбора области системный инструмент временно сохраняет PNG в уникальный временный файл; он удаляется после чтения/отмены. При аварийном завершении файл может остаться во временной папке.
- Ключи находятся в macOS Keychain. История защищена AES-GCM, ключ — в Keychain. Windows DPAPI-архивы не импортируются.
- Настройки, история и редактируемые инструкции: `~/Library/Application Support/GhostGPT`. Аудио и транскрипция на диск приложением не записываются. Текст разговора, использованный для ответа, уходит провайдеру; ответы сохраняются как чат.

## Настройка

В Настройках укажите адрес API с /v1, модель и собственный ключ. Для речи задайте отдельные адрес, модель и ключ. При первом старте записи подтвердите передачу аудио и предоставьте разрешения macOS на микрофон и запись экрана/системного аудио. После смены разрешений может понадобиться перезапуск приложения.

Ctrl+Shift+Space — вернуть/отправить назад; Ctrl+Shift+Enter — ответ по разговору; Ctrl+Shift+S — снимок; Ctrl+Shift+H — остановить всё и скрыть; Ctrl+Shift+Down — за другие окна. Клавиши меняются в настройках. Скрытие само по себе не останавливает запись.

## Статус проверки

CI собирает приложение и запускает unit-тесты, проверку подписи и запуск окна на Apple Silicon и Intel. Проверяется минимальная версия 13.0 как в Info.plist, так и в Mach-O; отдельно запускается интерфейс с принудительно включённым совместимым путём macOS 13. Хосты CI работают на macOS 15: это не проверка запуска на реальной Ventura. Это не заменяет проверку на пользовательском Mac. Живой провайдер, разрешения TCC, устройства, длительная запись, несколько мониторов и демонстрация Zoom/Teams/Meet/OBS должны быть проверены вручную. Поэтому macOS публикуется как prerelease до завершения этих проверок.

## Разработка

`cd macos && swift test`; `bash scripts/package-macos.sh arm64` (либо x86_64). Теги `mac-v*` запускают отдельную публикацию macOS; Windows Latest не заменяется.

## Полное завершение приложения

Кнопка питания справа в верхней панели доступна также в компактном режиме. Она открывает выбор: «Выйти и сохранить» завершает приложение штатно; «Завершить принудительно» немедленно останавливает процесс без сохранения последних изменений. «Отмена» оставляет приложение работающим. Кнопка скрытия и системный крестик по-прежнему только скрывают окно. Если интерфейс полностью завис и не реагирует на кнопки, используйте системное меню принудительного завершения macOS (Option+Command+Esc).
