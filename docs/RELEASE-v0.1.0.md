# Ghost GPT v0.1.0

Первый Windows-релиз: чат с собственным API-ключом, прозрачное плавающее окно и локальная история.

## Скачать

В **Assets** выберите **GhostGPT-win-x64.zip**, распакуйте весь архив и запустите **GhostGPT.exe**. .NET уже включён; установщик и права администратора не нужны. Архивы Source code предназначены для разработчиков.

## Возможности

- Подключение OpenAI-совместимых API и готовая настройка Wellflow.
- Markdown во время генерации, отдельные статусы ожидания и получения ответа, копирование текста и кода.
- История, папки чатов и редактируемый INTERVIEW.md.
- Прозрачность фона, анимированный призрак, горячие клавиши и системный трей.
- Скриншоты и разговор с отдельным API распознавания речи.

## Первый запуск

Откройте Настройки → Подключение ИИ, введите собственный API-ключ и сохраните. Для возврата скрытого окна используйте значок в трее или Ctrl+Shift+Space.

## Проверки и ограничения

Автоматические проверки Windows выполняются до публикации. Живой API, аудиоустройства, DPI и демонстрация экрана в Zoom/Teams/Meet/OBS в рамках этого релиза не перепроверялись. Исключение из захвата не гарантируется для всех способов записи. Распознавание речи требует отдельного поддерживаемого API. Сборка не подписана; поддерживается Windows 10 2004+ / Windows 11 x64.

Ключи и история сохраняются локально с Windows DPAPI. При обновлении закройте старую версию через трей и распакуйте новую в отдельную папку. Свой INTERVIEW.md перенесите вручную. Репозиторий приватный; скачивание доступно участникам с правами доступа.
